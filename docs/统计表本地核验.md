# 标准统计表本地核验

`standard_audit.py` 按 Excel 统计表中的完整标准号核验状态、发布日期、实施日期及其它公开字段。标准废止时，沿来源明确记载的替代关系继续查询，直到找到状态为“现行”的版本，并记录它的发布日期和实施日期。

这个命令只读原始统计表。所有原列、重复标准对应的不同文件记录都会保留；核验值写入新增列，不覆盖原来的状态、日期和现行版本。工作表中的说明和备注只是原始数据，不作为执行指令或已证实的结论。

## 安装与运行

在仓库根目录运行：

```bash
# 使用项目现有虚拟环境
uv pip install --python .venv/bin/python -r requirements-local.txt
# 也可以用 uv sync --extra audit 安装可选依赖

# 检查工作表和记录数，不访问网站、不生成结果
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx --dry-run

# 先试采前 20 行
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx --limit 20

# 采集整张表，重复运行会复用有效期内的查询缓存
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx

# 只核验一个标准，可重复指定 --standard
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx \
  --standard 'GB 150-1998'

# 重试请求失败、未匹配或存在冲突的记录
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx --retry-failed

# 强制重新采集全部选中记录
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx --refresh

# 只导出已经落盘的记录，适合意外中断后查看成果
.venv/bin/python standard_audit.py \
  ./标准信息统计表.xlsx --export-only
```

输入支持 `.xlsx` 和 UTF-8 CSV。第一行必须有“标准号”列，表头不可重复或为空。Excel 默认查找含“标准号”表头的工作表，可用 `--sheet 标准信息` 指定。`--limit` 计算原表行数，不是唯一标准数量；重复标准保留独立行并复用查询。

## 本地结果

默认结果目录为仓库中的 `local_audit/`：

| 文件 | 内容 |
| --- | --- |
| 标准信息核验结果.csv | 可用 Excel 打开。保留全部原表行，新增核验字段、现行版本及其日期、来源、核验结论和说明；未处理的行标记“未采集” |
| 核验记录.jsonl | 已处理行的完整结构化记录，包含原始值、各来源观测值、字段来源、现行版本及替代链 |
| 核验数据.sqlite3 | 每行采集结果及查询缓存，每完成一行立即提交，支持中断后复用 |
| 网页证据/ | 原始 HTML / JSON 响应字节，按内容 SHA-256 命名；字段证据记录相对路径、哈希、URL、请求参数和采集时间 |
| 运行摘要.json | 原表哈希、累计及本次处理数量、确认状态数量和生成时间 |

所有核验输出都保留原表行号。SQLite 以“原文件 SHA-256 + 原表行号”区分不同版本的表格，更新输入文件后不会把旧行结果错配到新表。

可用 `--output-dir /本地/目录` 更改结果目录；不能使用仓库根目录、`standard_db/` 或 `.crawl_state/`。自定义到仓库内部其它目录时，应把该目录加入 `.gitignore`。默认 `local_audit/` 已被忽略，本地核验命令不上传原表或结果。

## 数据来源与核验规则

| 来源参数 | 站点 | 用途 |
| --- | --- | --- |
| samr | [全国标准信息公共服务平台](https://std.samr.gov.cn/) | 官方国家、行业、地方标准高级检索与详情，明确的正向替代关系 |
| national | [国家标准全文公开系统](https://openstd.samr.gov.cn/) | 国家标准列表及详情，状态、采标标记、发布日期、实施日期等 |
| industry | [行业标准备案平台](https://hbba.sacinfo.org.cn/) | 行业标准官方状态、日期和基础信息 |
| local | [地方标准备案平台](https://dbba.sacinfo.org.cn/) | 地方标准官方状态、日期和基础信息 |
| csres | [工标网](http://www.csres.com/) | 第三方核对与补充。优先验证原表详情链接，无法验证时按标准号检索 |

默认使用全部来源，可用 `--sources samr,national,industry,local` 只查官方站点。

1. **完整标准号精确匹配**：统一全角字符、空格和横线；GBT、SYT 等明确的推荐标准前缀补全为 GB/T、SY/T，保留原表写法。编号、分册号及年份不变；不猜测 GBZ 等有歧义的前缀。检索命中后，详情页再次验证标准号。不能用同名或编号子串认定匹配。
2. **字段分别取证**：每个核验值记录来源 URL、请求参数、采集时间及响应快照。原表的数据来源链接只是检索线索，不自动成为新结果的证据。
3. **官方字段优先**：官方与工标网不一致时，采用官方值并保留冲突说明。同等权威来源对同一字段冲突时，该字段留空，进入人工复核。
4. **替代关系必须有明确方向**：只沿“被 XX 代替”或“被以下标准替代”等关系向前查询。“代替 XX”“代替以下标准”是前代关系，不填写为现行版本。不按年份较新、标准号相似或原表现行版本推断替代关系。
5. **验证替代版本的状态**：仅把查实为“现行”的终点写入“核验现行版本”。尚未实施的版本不能当作现行版本。一对多和多级替代保留全部分支；部分替代、缺失分支、循环、来源冲突或超过十级深度均记录复核原因。
6. **发布日期和实施日期分开**：发行日期按网站“发布日期/批准日期”处理，替代版本也分别记录两种日期。不会用实施日期补发布日期。
7. **缺失和失败保持可见**：未找到、站点不可达、验证码或结构变动不会推断为废止。保留可用官方列表证据，并单独记录详情失败。网页未给出的字段留空。
8. **保留文件信息**：文件名、文件大小、序号、原始备注及目录归类来自原表，不能由网页证实本地文件信息。核验“行业”和网站的“行业分类”分别保存，避免混淆标准领域与国民经济行业分类。

“核验结论”区分：官方来源已核验、仅第三方来源、需人工复核、待核查、未覆盖和未采集。“官方来源已核验”表示状态具有官方证据，不表示所有字段齐全，也不表示第三方站点访问成功；具体失败和字段缺失仍可查看。

当前国内来源不完整覆盖 ASME、ISO 等国际标准，国际标准行保留并标记“未覆盖”。缺少年份或不符合支持格式的标准号也进入人工核对。企业、团体、特种设备、计量和职业卫生类标准可能只能从工标网补充或仍需查原发布机构；“未查到”不等同于“无有效标准”。官方全文公开系统也有公开范围限制。

## 缓存、限速和故障

默认串行请求，每次间隔至少 1 秒；超时 15 秒，请求最多尝试 2 次。单个站点连续出现三次网络失败后，本次运行暂停该站点请求，下一次运行重新尝试。不会绕过验证码或访问限制。

查询缓存默认有效 7 天，包含失败和未匹配结果，避免重复冲击网站。使用 `--retry-failed` 重查失败、冲突或未确认状态的记录，使用 `--refresh` 强制刷新。缓存命中保留原证据采集时间，不伪造新鲜时间。原表中重复出现的标准号仍输出全部文件行。

`Ctrl+C` 会导出已完成的记录。进程被强制终止时，已提交 SQLite 的记录仍在；重新运行可利用缓存，或使用 `--export-only` 导出已有成果。

退出码：`0` 正常完成、只检查输入或只导出；`1` 输入/存储错误；`2` 本次处理的记录没有任何状态被确认；`130` 用户中断。退出码 `0` 不代表全部标准或替代关系均已确认，应检查核验结论和说明。

## 验证

```bash
.venv/bin/python -m pytest -q
```

离线测试覆盖精确匹配、替代方向、部分及多级替代、即将实施版本排除、循环、官方优先与冲突留空、日期区分、缓存重试、重复行保留和导出。

## 公开清单与本地补充

原始 Excel 留在本地，仅提交去重后的标准号清单：

```bash
.venv/bin/python scripts/public_input.py prepare ./标准信息统计表.xlsx
```

公开文件 `公开标准查询清单.csv` 只含标准类型和标准号，不包含原表行号、重复次数、文件名、大小、备注、链接或作者属性。GitHub 月度核验只读取这份公开清单。

下载公开核验结果 CSV 后，按标准号合并回原表的本地副本：

```bash
.venv/bin/python scripts/public_input.py merge ./标准信息统计表.xlsx ./reports/标准信息核验结果.csv
```

本地补充表保存在 `local_audit/标准信息统计表_已核验.xlsx`，保留原表中的重复行、原字段、公式和样式；未匹配结果明确标记未采集。原始 Excel 不被覆盖。
